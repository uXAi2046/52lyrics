# Asset provenance

52lyrics does not load remote artwork or typefaces at runtime.

- Album artwork and fallback artist marks are original abstract SVG compositions generated by `buildImageUrl` in `src/data/mockData.ts`. They use catalog metadata as deterministic seeds and contain no third-party photographs or logos.
- Imported artist photographs are stored in `public/artwork/imported/`. `src/data/imported/commons.json` records each image's author, source description page, license, download URL, retrieval time, encoded dimensions and SHA-256. Individual artist pages and the Copyright page expose attribution and licensing. These licenses do not extend to album covers or lyrics. Catalog cards lazy-load images; no runtime photo CDN is used.
- `public/favicon.svg` and `public/social-card.svg` are original project artwork created for this release candidate.
- Syne, Manrope, and IBM Plex Mono are bundled from their `@fontsource` packages. The root preloads the five WOFF2 weights used by the UI, and `font-display: swap` applies them when available. `optional` previously left some cold loads permanently on fallback fonts even after `document.fonts.ready`. The delayed-font regression checks actual heading/body glyph widths against an independently loaded reference face. Their upstream font licenses are included in the installed packages.
- Interface icons come from Lucide React under the ISC license.

No external image CDN or runtime font CDN is required by the release build.
