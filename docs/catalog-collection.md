# Online catalog collection

The original catalog and the eight reviewed Wikisource texts remain intact. Network imports add real release metadata and licensed photographs. Downloaded lyric source material is a separate stage: **a successful download is not approval to show a complete transcription**.

## Run the collectors

Run from the repository root with the project's Node and pnpm installation. Network access is required only for collection; the site serves local data and images.

```sh
node --import tsx scripts/catalog/collect-musicbrainz.mjs
node scripts/catalog/collect-images.mjs
node scripts/catalog/collect-lehrer.mjs
node scripts/catalog/collect-curated-releases.mjs
```

Run only one MusicBrainz collector at a time. Each source URL is cached under `.cache/catalog/` with its retrieval timestamp and SHA-256; repeating a collector reuses successful responses. Failed requests are not cached. Collectors use an identifying User-Agent, a hostname allowlist, bounded retries and a minimum three-second interval for uncached MusicBrainz requests. They do not sign in, evade access controls, purchase anything, or publish a deployment.

MusicBrainz selection targets the existing real-artist roster and 25 additional artists, up to three sourced studio-album editions per artist. Identity comes from the specific Wikipedia article's Wikidata MusicBrainz claims. New requests validate the primary artist credit; a release where the artist only participates is not promoted as their album. This is a curated import, **not a claim of complete discographies**. Selection can include bonus tracks in the actual referenced edition.

The separate curated-release collector runs after the main MusicBrainz collector. `scripts/catalog/curated-release-groups.json` pins four additional Tom Lehrer live/compilation release groups and their author-playlist evidence: An Evening Wasted With Tom Lehrer, Revisited, That Was the Year That Was, and The Remains of Tom Lehrer. It validates the group title and primary artist, then selects an actual official edition and preserves its full track sequence. The checkpoint adds 112 track entries, not 112 distinct lyric works. Publication merges `.cache/catalog/musicbrainz/curated.json` into the base checkpoint and checks that every configured target is present; repeating the studio-album import does not silently remove the curated releases.

Edition identity matters: the selected 1960 Revisited release has thirteen tracks, while the author's web playlist has fifteen. Do not splice one edition into the other. Live/Compilation labels remain in the source-edition credit. Multi-disc releases retain `discNumber` and `discTrackNumber`; The Remains of Tom Lehrer has 25, 24 and 25 tracks across three discs. Album rows and the lyric page display the disc-specific position rather than pretending all 74 tracks are on one disc.

Images are resolved from the article's lead image to Wikimedia Commons. Only the supported public-domain, CC0, CC BY and CC BY-SA licenses are imported; missing or unsupported licensing is logged rather than inferred. A photograph's license is independent of song, recording and album-sleeve rights. The manifest preserves the artist/attribution, description-page URL, license URL, original/download URLs and hashes. Publication reads the actual encoded PNG/JPEG dimensions because requested thumbnail dimensions may differ from delivered files.

## Validate and promote a checkpoint

```sh
node scripts/catalog/publish-batch.mjs musicbrainz
node scripts/catalog/publish-batch.mjs images
pnpm check
pnpm lint
pnpm test
pnpm exec playwright test tests/e2e/sourced-catalog.spec.ts
pnpm build
```

Promotion reads only cached data and local images and writes atomically to `src/data/imported/`. It checks image hashes and source links, compares complete track sequences against the downloaded release response, and excludes artist-credit mismatches and existing album-title aliases (such as Divide / ÷). The imported JSON retains exclusions and failures; a checkpoint with failures is **not a completed bulk collection**. Inspect those lists before reporting completion. No lyrics, producer credits, or songwriter credits are invented for metadata-only imports.

`pnpm catalog:verify-sources` repeats the source comparison without publishing or fetching anything. It requires the local collection cache, checks every configured artist and every promoted release's primary credit, complete track IDs/titles/recordings/disc positions, verifies all local photo and author-document hashes, and accounts for every author source as approved or held. On a clean checkout, run the collectors first to restore the cache; the ordinary unit tests and production build do not require network access or this private cache.

`src/data/externalCatalog.ts` adapts the source data without changing existing IDs/slugs, so older saved items and links remain resolvable. Artist, album and recording pages show source links. `/copyright` contains the photograph attribution ledger. Abstract album art is explicitly distinguished from original sleeves. The album archive is available in Discover. Explicit source-data corrections are quarantined in `scripts/catalog/metadata-exclusions.json`, with evidence links; an API's Official status alone does not override contradictory primary evidence.

## Lyric-review queue

The Tom Lehrer collector accounts for all 96 song pages and six album/disc playlists in its cached source inventory. Ninety-four pages provide separate lyric PDFs; My Home Town and Hey, Joe provide score PDFs, and Hey, Joe also provides a DOCX lyric document. Each PDF is labeled `lyric-sheet` or `score`; DOCX files have their own URL, filename, format and checksum. The former two document-format exclusions have been processed, not silently treated as empty full lyrics.

- Downloaded documents and the complete source inventory: `.cache/catalog/lehrer/`.
- Versioned document URLs/hashes, album track lists and review status: `src/data/imported/lehrer-sources.json`.
- Coordinate-aware extraction: `scripts/catalog/extract-lyrics.py` (Python with `pdfplumber`).
- Render a source for visual comparison: `pdftoppm -f 1 -singlefile -scale-to 1200 -png INPUT.pdf tmp/pdfs/source`.

PDFs include scanned-only pages, alternate versions, printed notes and two-column text. The embedded OCR has demonstrable errors (for example, merged columns in We Will All Go Together When We Go). Compare against rendered originals, preserve the chosen version and credits, and keep a reviewed correction manifest before enabling full lyrics. `src/data/reviewedLyrics.ts` explicitly approves the first visually compared sheet, Poisoning Pigeons in the Park (41 lines in six stanzas), with its pinned PDF checksum. The 18 earlier original/historical works remain available.

Another 89 visually checked works are specified by exact page/line bounds or an explicit score reading order, stanza sizes, corrections and PDF hashes in `scripts/catalog/lehrer-review-manifest.json`. Together they contribute 2,998 text lines, including identified performance directions. There are now 90 reviewed Tom Lehrer works: 46 recording-associated texts plus 44 explicit author-songbook placements. Both Songs by Tom Lehrer editions now have all twelve tracks readable; More of Tom Lehrer and An Evening Wasted With Tom Lehrer each have all eleven, and That Was the Year That Was has all fourteen. The Remains of Tom Lehrer has 73 readable entries out of 74; its spoken Introduction remains metadata-only. All 96 collected song sources are accounted for: 90 approved and six explicit rights holds. **Held sources do not count as complete lyrics.** This covers one documented reading edition per approved work, not every alternative text or performance.

The current site has 57 artists/writers, 168 albums/songbooks, 1,912 song entries and 48 local licensed photographs. Its 207 full-lyric entries represent **108 distinct works**, including the ten originals and eight historical texts; different album appearances do not inflate the distinct-work count. Eleven reviewed educational texts are also reachable through Discover's The wordplay classroom collection and Learning filter, including Unsong and Why Not Fight? Run `pnpm catalog:stats` for authoritative counts after any import, including separate approved, pending and held author-source counts.

### Author sheets without a verified recording edition

`src/data/authorSongbook.ts` creates the explicitly editorial **Tom Lehrer: Author Lyric Sheets** songbook at `/albums/tom-lehrer-author-lyric-sheets`. It contains forty-four reviewed texts (1,432 lines), including classroom wordplay, campus/science satires, theatre numbers and reflective lyrics. The latest fourteen texts contribute 517 lines; existing track IDs and positions remain unchanged. The book reuses the existing sourced artist and licensed portrait, with original abstract book artwork. It does not fabricate a studio album or attach a text to an unverified recording. Every text is searchable and appears in The wit of Tom Lehrer discovery collection and the artist's mixed release/songbook shelf.

Only reviews explicitly marked `catalogPlacement: "author-songbook"` enter this reading selection. Omitted placement defaults to `recorded-release`; a misspelled or orphaned recording review does not silently become a songbook. Date fields use `year` / `releaseYear: null` and `releaseDate: ""` for these undated text editions. Pages display **Undated text** or **Author-published texts**, search does not index the string `null`, and structured data omits an unknown `datePublished`. A source's writing date or website timestamp is not treated as a recording release date. Songbooks use `CreativeWorkSeries`, not `MusicAlbum`.

Every selected PDF page was visually compared before publication. The Derivative Song uses the complete first-page nine-line text rather than duplicating the screen-caption version on page two. Don't Major in Physics expands its two explicit Chorus cues from the same printed four-line refrain. Are There Any Questions retains the two printed voice parts and explains the three student entry markers; Fugue for Scientists retains all speaker parts. Alternate names, later substitutions and optional opening verses are described separately instead of being spliced into the main text. Source musical-setting credits remain in About; no recording or score is published. Adaptations retaining another writer's words or translating an older work require the separate evidence described below.

`src/data/imported/lehrer-rights-holds.json` records source-specific reasons for withholding approval. **All Is Well** credits French lyrics to Bach and Henri Laverne; **The Bourgeoisie** credits Jacques Brel; **Juca** and **Sunshine / Bom Tempo** credit Chico Buarque; **Shakespeare Lied** identifies original lyrics by Carolyn Leigh and an adaptation by Lehrer. The visible author-sheet credits were checked; Lehrer's declaration alone is not treated as clearance of these underlying texts. Both the review publisher and the catalog adapter reject a review on this hold list. This is a local pending-rights decision, not a claim about a work's legal status in every jurisdiction and not a blocker for unrelated original texts.

**Hey, Joe!** is the sixth hold. The full one-page DOCX was rendered and compared with the one-page score. The two simultaneous parts have separate authors: Lehrer for the English words and Giovanni Capurro for the Neapolitan 'O Sole Mio part. The DOCX also credits Eduardo di Capua and Alfredo Mazzucchi for the earlier music. The original text's publication date alone is not treated as proof of worldwide clearance; [EU term rules for music with words](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32011L0077) require a separate applicability review. The independent English part is not mislabeled as the complete duet. Source bytes and credits are retained locally, with no full-lyric entry published for this work.

The second author-book batch keeps complete, explicitly chosen versions. Polaroid Photography Song uses the 1980 long text with every chorus, not an amalgam with the separate 1972 short version. The Menu Song retains the author's printed ending and explains that it differed on television; a suspect date in a historical footer is not promoted into release metadata. The Ice Cream Tango excludes its optional framing scenes. He's Not the One and Take Me for a Walk explicitly identify their uncomposed status; character initials, spoken interludes and stage directions remain visible, while optional extra lines stay separate. Scenery ends at the crew's final reply rather than inventing another chorus. Exact scan corrections include pentadactyl, fressing and a split stage cue; deliberate scientific rhymes, mumbling and source spellings are not automatically corrected.

The final lyric-PDF batch preserves role and version boundaries. The Professor's Song selects the complete physics version, including superscripted formulas, without adding the separate mathematics variant. The SAC Song uses its identified movie version, not the unused second-page verses. Sociology retains the three main verses and labels the fourth as an extra verse. We're Talkin' Algebra expands three explicit refrain cues into the same ten-line chorus. Unsong retains scripted replies and actions and is described as an unproduced project. Why Not Fight? separates the one merged two-column line and uses editorial singer/cheering-section prefixes.

Te Amo and s = ½ gt² have parallel-column duet parts. Reviewed rectangles extract both voices independently; each pair is ordered one voice at a time for linear reading, with the performance overlap explained in About. Te Amo retains both source languages and printed accents. Optional `sectionLanguages` emits paragraph-level `lang="es"` / `lang="en"` attributes while navigation stays English. The publisher requires an explicit edition and exactly one supported language per section.

Four adaptations have `underlyingWork` records with original writers, evidence URLs and rights notes:

- I Can't Think Why credits W. S. Gilbert and the [Library of Congress's 1884 Princess Ida libretto](https://www.loc.gov/resource/music.musschatz-21647/), whose collection is identified as public domain.
- The Night I Appeared as Macbeth credits William Hargreaves. The [author-published score's first-page statement](https://tomlehrersongs.com/wp-content/uploads/2019/03/the-night-i-appeared-as-macbeth-music.pdf) explicitly identifies the original as public domain; [the revue publisher](https://www.nickhernbooks.co.uk/plays-to-perform/the-shakespeare-revue) confirms original/revised credits.
- Trees credits Joyce Kilmer and [Project Gutenberg's 1914 edition record and US public-domain label](https://www.gutenberg.org/ebooks/263). The adapted lyric does not append the original poem.
- Tango de la Menegilda credits Felipe Pérez y González, supported by [SGAE's original-work record](https://archivo.sgae.es/heritageobject/la-gran-via-544f/), [BNE's author dates](https://datos.bne.es/persona/XX4579027) and [edition history](https://www.bne.es/es/colecciones/partituras/teatro-lirico/gran-via). Only the complete English adaptation is displayed, not an interleaving with the facing Spanish column.

These sources are separate from Lehrer's declaration for his revisions/translation; none licenses later third-party recordings or artwork. Visible credits, copied attribution and JSON-LD retain all credited writers. Search now indexes `song.writers`. Original-work evidence is displayed and included in copied text. The publisher rejects incomplete provenance records; manual source review, not a schema assertion alone, is the basis for approval.

Rebuild approved texts from the source documents:

```sh
CATALOG_PYTHON=/path/to/python-with-pdfplumber node scripts/catalog/publish-reviewed-lyrics.mjs
pnpm test
pnpm build
pnpm catalog:verify-build
```

Each review uses zero-based `page` and half-open `start`/`end` line ranges. For two-column pages, add an explicit PDF-coordinate `bbox: [x0, top, x1, bottom]` to each range and list ranges in reading order. The extractor uses only these reviewed rectangles; it does not guess column order. The publisher re-extracts pinned PDF bytes on every run, checks that each selection is in bounds, and checks stanza and correction counts before atomically writing `src/data/imported/lehrer-reviewed.json`.

Image-only documents use an explicit manual path, currently Alma, Speed's Song and The Subway Song: `pages: []`, `manualPages` covering every page, and visually transcribed `manualLines`. The publisher permits this only when every freshly extracted page has zero text lines, checks the complete page list, and still verifies the pinned PDF hash and stanza totals. It never automatically fills a failed extraction with invented text. Alma's 47 lines follow all twelve source blocks; Speed's Song retains sixteen lyric lines without the separate Shakespeare dialogue; The Subway Song retains eight lines without the historical notes. New Math retains 79 spoken/sung lines from two pages; its marginal arithmetic is described in About rather than merged into the lyric paragraphs.

Scores use a separate manual review mode, not an exception that lets arbitrary OCR through. My Home Town's four pages contain noisy notation/OCR and two lyric rows sharing the same melody. Its `scoreReading` records the upper-row traversal, the repeat into the lower row and the final single-row coda. Every stanza has page references, its lyric row and a contiguous half-open line range; `validate-score-reading.mjs` rejects missing pages, gaps, overlaps, missing repeat instructions and non-score sources. The complete reading has 36 lines in seven editorial sections and preserves the printed `(Hum)` cue without supplying invented words. The source hash is checked as usual. All five existing release-track entries receive the same explicitly identified score edition; their IDs and release metadata remain unchanged. The reader labels the source link **Read the author's score (PDF)** rather than calling it a separate lyric sheet.

Corrections are exact whole-line replacements, never generic OCR cleanup. A string replacement must match once; a repeated correction declares `{ "text": "replacement", "occurrences": 2 }` and must match that count. Printed odd spellings remain when they are visible in the source. Stage directions remain distinct from missing lyrics: Lobachevsky has two editorial bracketed cues for Russian ad-libs that the author deliberately leaves unspecified. No words from an arbitrary recording have been invented to fill them.

The chosen main version is always documented in the song's About text. Alternate endings, later Tomfoolery bridges, U.K. replacement verses, and musical footnotes are not silently mixed into it. Who's Next explicitly identifies the later author-sheet wording instead of claiming a verbatim 1965 recording transcription. That's Mathematics excludes the expressly optional Wiles verse, Silent E uses the Electric Company sheet rather than its private variant, and Selling Out prints the four character parts once instead of inventing repeats from the separate performance routine. Optional `sectionLabels` retain source headings, such as Clementine's four named sections, in the reading rail and clipboard output. `normalizeCatalogText` equates typographic/straight quotation marks and ordinary/typographic hyphens for matching, without changing stored titles, slugs, or saved-item IDs. An approved title must resolve to sourced release tracks or an explicit editorial songbook placement; tests reject orphaned reviews.

`catalog:verify-build` checks every generated artist, album, and song detail page, including the exact text/order of every lyric line, source section headings, album track order and disc positions, canonical URLs, source links, local photograph checksums, songbook schema types and omitted unknown publication dates. A valid source manifest alone does not prove that the reader renders the right text. Browser regressions cover the new full albums, long lyrics, image-only transcription, punctuation-normalized search, educational discovery route and author songbook search → reading → book → saved-after-refresh → artist path. Assertions select an explicit album edition when titles repeat and scope lyric-body checks to section paragraphs, excluding editorial context.

Long-text reading is tested in both scroll directions. The reader selects the last heading above a viewport reading line in an animation-frame-throttled scroll/resize handler; a narrow IntersectionObserver band previously left the final section highlighted when scrolling back through a long introduction. When the active section changes, only the horizontal rail is scrolled to reveal its button, without moving the page. Inactive controls use AA-readable Dust Grey, and the mobile rail has an opaque background so underlying text does not compete with the controls. The Alma regression verifies both first-section highlighting and button visibility after returning from the last stanza.

Responsive checks compare document width against Playwright's configured device width, not `window.innerWidth`: mobile Chromium can enlarge both `innerWidth` and the layout viewport when content overflows. The old comparison therefore missed a 390px homepage expanding to 404px and a lyric page expanding to 394px. Isolated CSS probes identified the mobile record decoration's negative right inset and the rail's tablet-sized negative margins. The narrow-screen rules now keep the decoration inside its container and match the rail to the actual 1rem shell gutter. Regression cases cover 360px, 390px and 768px; no body-wide overflow hiding masks the problem.

Full-page visual captures explicitly wait for fonts, local-library hydration and all images, including offscreen lazy artwork, then allow two animation frames for the resulting paint. This test-only preparation does not change production lazy loading or screenshot tolerances. Snapshot updates were reviewed for changed catalog counts, curated entries, source notes, related titles and the verified mobile width correction. A snapshot update is not itself a passing regression: rerun `pnpm test:e2e` without `--update-snapshots` before accepting the checkpoint.

The full run also exposed font-selection instability: `font-display: optional` could keep a fallback font after a slow download, despite the FontFaceSet reporting loaded. A 1.4-second delayed-font probe reproduced different actual glyph widths; replacing only the display policy with `swap` applied the intended local font. The root now preloads the five bundled WOFF2 faces and the stylesheet permits swapping. `fonts.spec.ts` compares heading and lyric-line widths against a separately loaded reference face after delayed responses, rather than trusting the declared CSS family or `document.fonts.ready` alone. See [font-display behavior](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@font-face/font-display). Slow-load CLS and the complete Lighthouse release gate still require measurement; preloading alone is not proof of those targets.

## Source policies

- [MusicBrainz core-data license](https://musicbrainz.org/doc/About/Data_License): core facts are CC0; supplementary data is not imported.
- [MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API) and [rate limits](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting): public API access has its own usage terms, distinct from data licensing; commercial API use requires the appropriate plan. The public site consumes only the static snapshot, never the API.
- [Commons credit lines](https://commons.wikimedia.org/wiki/Commons:Credit_line/en): retain file-specific attribution and reuse terms.
- [Tom Lehrer's author statement](https://tomlehrersongs.com/): release of his lyrics and compositions does not transfer third-party music, photographs or sleeve artwork.

The source-format queue is now empty: My Home Town is approved and Hey, Joe is explicitly held after document review. The six rights holds stay unpublished unless separate evidence supports approval. This is not a claim that every document variant or every recording has a complete transcription. Collectors have no unresolved metadata or photo failures; source exclusions remain explicit. Vercel Preview, production deployment, and the complete Lighthouse release audit are separate from this local content-collection delivery.
